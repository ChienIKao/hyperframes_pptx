# QA 驗收

第一次建置通常會有幾個小問題。找出來、改 `deck.md`、重建、停。

## 1. 建置訊息

`build` 會印出使用的版面對應與 ⚠ 警告（找不到圖片、SVG、文字可能溢出、表格過長）。每條都要處理。

## 2. 內容檢查

```bash
python <skill>/scripts/build_deck.py dump output/<slug>.pptx
```

逐頁列出版面、標題、文字、圖片、表格、備註，並標記：
- `⚠ 超出投影片邊界`
- `⚠ 文字可能溢出`（估算值，偏保守；和預覽圖交叉確認）

對照 `deck.md` 檢查：漏頁、順序、錯字、該進備註的有沒有進。

## 3. 目視檢查

```bash
python <skill>/scripts/preview.py output/<slug>.pptx
```

以 PowerPoint（Windows COM）或 LibreOffice 渲染，產生 `output/<slug>_preview/grid.png`，用 Read 看這張圖。逐頁看：

- 文字是否超出框、被截斷
- 左文右圖時兩邊比例是否合理（不合理 → config 的 `text_ratio`）
- 圖片是否太小（素材解析度或長寬比問題）
- 章節頁、封面在模版上的位置是否正確（不正確 → 多半是 `layouts` 對錯版面）
- 殘留的「按一下以新增文字」空框（腳本會刪空佔位框；若仍有，回報 bug）

需要看細節時直接 Read 單頁 PNG。

## 常見問題 → 修法

| 症狀 | 修法（改 `deck.md` 或 config，然後重建） |
|---|---|
| 一頁字太多、字很小 | 用 `---` 手動拆頁；或（精煉模式）長句改短條列，原文進 `<!-- -->` |
| 表格擠 | 減欄；或拆成兩張表 |
| 圖太小 | 讓該頁只放圖（文字移到上一頁或備註） |
| 目錄太長 | 章節 > 8 個時考慮合併章節，或 `agenda: false` |
| 中文字型不對 | 主題/模版 config 設 `fonts.ea` |
| 用錯版面 | `templates/<slug>/config.json` 的 `layouts` 指定正確名稱 |
| 章節頁編號格式 | front matter `section_label`（模版模式） |
| 導覽列子章節擠在一起、字變很小 | 子章節名稱縮短（建議 ≤ 6 字），或把該章拆成兩章 |
| 元件大片留白或擠壓 | 調整項目數（cards/stats 以 2–4 項最佳），或換元件：項目多→`steps`，有比較→`compare` |
| 左欄文字被縮到很小 | 左欄 ≤ 5 條；細節移到 `<!-- -->` 或用 `---` 拆頁 |
| 強調色塊沒出現 | `==詞==` 前後不能有空白；舊版 PowerPoint（2016 以前）不顯示螢光筆效果 |
| 章節頁右側空白 | 該章沒有 `###` 子章節；加上子章節，或在 `##` 下寫一句短介紹（會顯示在卡片中） |

## 腳本做不到的事

需要圖表（原生 chart）、SmartArt、特殊排版時：先完成主流程，再用 `anthropic-skills:pptx` 針對特定頁面加工，並在交付時註明哪幾頁是手工加工（重建會被覆蓋）。
